## nextCP/2 5.0.3

### Highlights

- Needs media server UMS Version 16+ for all features!
- Video playback support on "This device" (running browser instance)
- Moved AudioAddict support to UMS with ICY metadata support!
- Updates ICY metadata in UI from WebStreams, even then when the renderer doesn't support it.
- Updates UI on push notification from UMS (file change events on server file system)!

### Downloads

- **macOS**: `nextCP2-*.dmg` (installer) or `nextCP2-macos.zip` (portable app image).
- **Windows**: `nextCP2-*.msi` (installer) or `nextCP2-windows.zip` (portable app image).
- **Any OS with a JRE 25**: `nextcp2.jar` (run with `java -jar nextcp2.jar`).
- **Docker**: `docker pull ghcr.io/sf666/nextcp2:5.0.3` (or `:latest`) — see the [Docker install guide](https://sf666.github.io/nextcp2/quick_install/docker/).
- **McIntosh MA9000/MA12000 driver**: `nextcp2-ma9000.jar` (optional).
