## nextCP/2 5.1.2

### Highlights

- Every direct playlist entry now offers a removal action in its options menu, including videos and linked containers.
- Large library lists, grouped album grids, full search results, radio collections, the playlist sidebar, and the player queue render only the entries around the viewport and load cover art as needed.
- With the default page size, large UMS library views fetch the first page normally and use larger background requests for the remaining entries. Filters still use the full listing.
- Long library views offer a discreet Back to top button below the browse header.
- Updated the web UI to Angular 22.3.0, including Angular CLI, Material, and CDK. Updated Angular ESLint to 22.8.0.

### Downloads

- **macOS** `nextCP2-*.dmg` (installer) or `nextCP2-macos.zip` (portable app image).
- **Windows** `nextCP2-*.msi` (installer) or `nextCP2-windows.zip` (portable app image).
- **Any OS with a JRE 25** `nextcp2.jar` (run with `java -jar nextcp2.jar`).
- **Docker** `docker pull ghcr.io/sf666/nextcp2:5.1.2` (or `:latest`). See the [Docker install guide](https://sf666.github.io/nextcp2/quick_install/docker/).
- **McIntosh MA9000/MA12000 driver** `nextcp2-ma9000.jar` (optional).
