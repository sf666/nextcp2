Displays currently active player song. Song can be added to server playlist or star rated.

<Image src={nowListening} alt="" class="" />

The active player is chosen with the <span class="material-symbols-outlined">speaker</span> button in the player bar.
Besides your external UPnP media renderers, the list includes **This device** — selecting it plays the music directly
in the current browser, turning the tab you are viewing into the player. Options for the built-in browser player
(pre-transcoding and cache directory) are described under [App Settings](/nextcp2/user_interface/app_settings/).
